# 큐/상태값 레지스트리 (Discord 채널 매핑 포함)

> 모든 routine.yaml은 큐 이름을 이 문서 기준으로 참조한다.
> Discord 채널ID는 아직 미정 — 채널 생성 후 `discord_channel_id` 칸만 채우면 된다.
> bot 코드는 이 문서를 설정 소스로 읽어들인다 (하드코딩 금지).

## 사용법

1. 실제 Discord 서버에 아래 `discord_channel_name` 기준으로 채널을 생성한다.
2. 생성 후 채널을 우클릭 → ID 복사 → `discord_channel_id`에 채운다.
3. bot 코드는 이 표를 파싱해서 큐 이름 → 채널ID 매핑 딕셔너리를 만든다.

## 큐 목록

### 1. `content_editor.inbox`

- **의미**: 서연우가 승인한 키워드 후보 대기열
- **쓰는 직원**: 서연우
- **읽는 주체**: 한도윤 (자동, event-driven)
- **discord_channel_name**: `#서연우-키워드큐`
- **discord_channel_id**: (미정)
- **메시지 형식**: keyword, urgency_level, intent_type, reason 포함 embed

### 2. `compliance_review.queue`

- **의미**: compliance_risk=high 또는 민감 키워드/조정 대기열
- **쓰는 직원**: 서연우, 정하준
- **읽는 주체**: 법무팀 (사람)
- **discord_channel_name**: `#컴플라이언스-검토`
- **discord_channel_id**: (미정)
- **메시지 형식**: 원본 데이터 + compliance_note + 승인/반려 버튼
- **주의**: 이 채널은 접근 권한을 법무팀+마케팅팀장으로 제한 권장 (민감 키워드 노출 최소화)

### 3. `human_review.queue`

- **의미**: 한도윤 콘텐츠 초안 중 flagged_claims 있는 항목 대기열
- **쓰는 직원**: 한도윤
- **읽는 주체**: 변호사 (사람)
- **discord_channel_name**: `#콘텐츠-검수대기`
- **discord_channel_id**: (미정)
- **메시지 형식**: 초안 전문 + flagged_claims 목록 + 승인/반려 버튼

### 4. `publish_queue`

- **의미**: 검수 불필요 판정된 콘텐츠 최종 발행 대기열
- **쓰는 직원**: 한도윤
- **읽는 주체**: 발행 담당자 (사람)
- **discord_channel_name**: `#발행대기`
- **discord_channel_id**: (미정)
- **메시지 형식**: 초안 전문 + 최종 확인 버튼

### 5. `auto_apply_queue`

- **의미**: ±20% 이내 광고 조정안 (자동 반영 가능하나 최종 확인 필요)
- **쓰는 직원**: 정하준
- **읽는 주체**: 마케팅팀 (최종 확인 후 반영)
- **discord_channel_name**: `#정하준-자동조정대기`
- **discord_channel_id**: (미정)
- **메시지 형식**: keyword, action, adjustment_percentage, rationale + 확인 버튼

### 6. `human_approval.queue`

- **의미**: ±20% 초과 조정 또는 PAUSE — 승인 필수
- **쓰는 직원**: 정하준
- **읽는 주체**: 마케팅팀장 (사람)
- **discord_channel_name**: `#광고조정-승인필요`
- **discord_channel_id**: (미정)
- **메시지 형식**: 동일 + 승인/반려 버튼 (반려 시 사유 입력 유도)

### 7. `data_assistant.tracking_status`

- **의미**: 상시 갱신되는 트래킹 상태값 (Normal/Warning/Critical)
- **쓰는 직원**: 오지민
- **읽는 주체**: 정하준 (매 실행 전 조회), 사람(상시 모니터링용)
- **discord_channel_name**: `#오지민-트래킹상태`
- **discord_channel_id**: (미정)
- **메시지 형식**: 30분마다 상태 요약 (Normal이면 조용히, Warning 이상만 게시 — 채널 도배 방지)

### 8. `broadcast.all_agents`

- **의미**: 오지민의 Critical 판정 시 전체 직원+사람에게 긴급 전파
- **쓰는 직원**: 오지민
- **읽는 주체**: 서연우, 한도윤, 정하준 (자동), 개발팀+마케팅팀장 (사람)
- **discord_channel_name**: `#전체-긴급알림`
- **discord_channel_id**: (미정)
- **메시지 형식**: 이상 유형 + 영향받는 직원 명시 + `@here` 또는 관련 role 멘션

### 9. `dev_team.queue`

- **의미**: 시스템 오류(파싱 실패, API 무응답, GTM 오류 추정 등) 대기열
- **쓰는 직원**: 서연우, 한도윤, 오지민
- **읽는 주체**: 개발팀 (사람)
- **discord_channel_name**: `#개발팀-에러알림`
- **discord_channel_id**: (미정)
- **메시지 형식**: 에러 유형, 발생 직원, 타임스탬프, 관련 로그 링크

### 9-1. `pattern_alert.queue`

- **의미**: 개별 항목이 아닌 통계/반복 패턴 기반 경고 (반려율 추세, 연속 반려 등)
- **쓰는 직원**: 한도윤, 정하준
- **읽는 주체**: 마케팅팀장 (사람)
- **discord_channel_name**: `#패턴경고`
- **discord_channel_id**: (미정)
- **메시지 형식**: 트리거 조건, 최근 수치, 관련 항목 링크(agent_memory 조회 결과)
- **비고**: 개별 승인 버튼 없음 — 통계 경고이므로 "확인" 반응(이모지)만으로 충분

## DB 전용 (Discord 채널 없음)

### 10. `agent_memory`

- **의미**: 각 직원의 최근 작업 이력 (승인/반려 결과 포함)
- **저장 위치**: DB (SQLite/PostgreSQL), Discord 채널 아님
- **이유**: 구조화 쿼리 필요 ("최근 7일 반려 건수" 등), 메시지 삭제 시 유실 위험 방지

### 11. `audit_log`

- **의미**: 모든 판단 근거, 모델/프롬프트 버전, 라우팅 결과 영구 기록
- **저장 위치**: DB, 변경 불가(append-only)
- **이유**: 감사 대응용, Discord 메시지 삭제와 무관하게 보존되어야 함
- **참고**: Discord 메시지에는 이 로그의 레코드 ID를 포함시켜, 나중에 메시지 ↔ DB 레코드를 상호 추적 가능하게 한다.

## 채널 권한 설계 가이드 (참고)

| 채널군                                   | 권한 범위                                              |
| ---------------------------------------- | ------------------------------------------------------ |
| `#컴플라이언스-검토`, `#콘텐츠-검수대기` | 법무팀, 변호사, 마케팅팀장만 (민감정보 최소 노출)      |
| `#광고조정-승인필요`                     | 마케팅팀장, 마케팅팀                                   |
| `#전체-긴급알림`, `#개발팀-에러알림`     | 개발팀 전체 + 관련자                                   |
| `#패턴경고`                              | 마케팅팀장, 마케팅팀 (통계 추세 모니터링용)            |
| 나머지 큐 채널                           | 마케팅팀 전체 열람 가능 (승인 권한은 role로 별도 제한) |

## 이 문서가 바뀌어야 할 때

- 새 큐가 추가되거나 기존 큐의 라우팅 규칙이 바뀔 때 (각 직원 routine.yaml과 동시 갱신)
- Discord 서버 채널 구조가 재편될 때
